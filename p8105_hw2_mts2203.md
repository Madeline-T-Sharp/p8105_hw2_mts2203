nyc_transit_df =

  select(line, station_name, station_latitude,  station_longitude,

         entry, vending, entrance_type, ada

      "YES" ~ TRUE,
      "NO" ~ FALSE

## Short paragraph about the dataset

The `NYC_Transit_Subway_Entrance_And_Exit_Data.csv` dataset contains
variables Division, Line, Station Name, Station Latitude, Station
Longitude, Route1, Route2, Route3, Route4, Route5, Route6, Route7,
Route8, Route9, Route10, Route11, Entrance Type, Entry, Exit Only,
Vending, Staffing, Staff Hours, ADA, ADA Notes, Free Crossover, North
South Street, East West Street, Corner, Entrance Latitude, Entrance
Longitude, Station Location, Entrance Location. I created data frame
`nyc_transit_df` to import and clean the data from the
`NYC_Transit_Subway_Entrance_And_Exit_Data.csv` dataset. First, I used
`read_csv()` read the csv file, second, I standardized the column names
using `janitor::clean_names()`, third, I selected for the columns line,
station_name, station_latitude, station_longitude, route1, route2,
route3, route4, route5, route6, route7, route8, route9, route10,
route11, entry, vending, entrance_type, ada, and finally I used the
`mutate()` function to change the `entry` column data type from
`character` to `logical`. The function `case_match()` was essential to
accomplishing the last task. The resulting `nyc_transit_df` dataset’s
dimensions are1868 rows by 19 columns. No, this data is not yet tidy.
The route columns should be better consolidated, the vending column
could be a logical instead of a character data type, and the missing
values have not been dealt with.

## Reformatting data

``` r
# reformatting data to make route number ad route name distinct variables
nyc_transit_routes = 
  nyc_transit_df |>
  mutate(
    across(
      starts_with("route"), as.character
      )
  ) |>
  pivot_longer(
    route1:route11,
    names_to = "route_number",
    names_prefix = "route",
    values_to = "route_name"
  ) |>
  drop_na(route_name)
```
