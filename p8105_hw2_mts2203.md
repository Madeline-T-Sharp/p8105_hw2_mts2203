## Reading and cleaning the Problem 3 data

``` r
# importing and tidying MCI_baseline csv data
mci_baseline_df =
  read_csv(
    file = paste0(
      "p8105_hw2_mts2203_files/",
      "MCI_baseline.csv"),
    skip = 1,
    na = c("", "NA", ".")
  ) |>

  mutate(
    sex = case_match(
      sex, 
      1 ~ "male",
      0 ~ "female"
    ),
    apoe4 = case_match(
      apoe4,
      1 ~ "carrier",
      0 ~ "non-carrier"
    )
  ) |>
  filter(
    age_at_onset > current_age | is.na(age_at_onset)
  )
```

## Discussing the MCI baseline demographics dataset import and features

The MCI_baseline.csv dataset was imported as `mci_baseline_df`. To
import the csv file, I used the `read_csv()` `tidy` function. To clean
the data, first skipped the first line of the dataset. This line
contained notes that were unnecessary to include considering the clarity
of many column variable names. However, for those column variables
without such clarity, I used the `mutate()` function, with
`case_match()` nested within it, to recode their values; thus,
amplifying their clarity. To ensure that all participants met then ‘no
MCI at baseline’ criterion, I used the `filter()` function to isolate
those whose `age_at_onset` exceeded `current_age`, as well as those who
remained MCI free after follow-up, i.e., the NAs. In other efforts to
clean this dataset, I standardized across several categories. These
included the presentation of missing variables, and the presentation of
column variables. The latter task was completed via the `clean_names()`
function in the `janitor` package. The tidy `mci_amyloid_df`dataset has
479 rows and 6 columns. These are its column variables: id, current_age,
sex, education, apoe4, age_at_onset. In summary, 479 participants were
recruited, 93 of them developed MCI, 65.0286013 was the average baseline
age, and 0.3 was the proportion of women in the study who were APOE4
carriers.
